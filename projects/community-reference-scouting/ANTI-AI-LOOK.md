# Anti-AI-look：候选筛选与 PR20 的接口

本文件不取代 [PR20 已有 Anti-AI-Look Pass](https://github.com/yichengzhao46-rgb/codex-workbench/blob/c4dea1b31db6b022e73e29967a0f02c959e39bcb/projects/scientific-figure-style-corpus/ANTI-AI-LOOK-PASS.md)。它把上游社区建议转换为可讨论的检查项，不新增另一个评分体系。

“AI 感”在这里指不必要的渲染和语义不一致，不用于判定作者身份，也不用于隐瞒模型参与。

| 检查 | 不通过的具体表现 | 修正 | 依据 |
| --- | --- | --- | --- |
| 科学内容锁定 | 额外蛋白、无依据电子箭头、假结构 | 回到当前任务的 science lock；删除未支持对象 | R13 / R17，PR20 |
| 表面与背景 | 塑料光泽、统一辉光、装饰浮粒 | 哑光、干净背景、只保留信息性纹理 | R14；S001 / PR20 |
| 深度 | 相互矛盾的视角、阴影遮文字 | 统一同一场景的视角；必要时改为平面剖面 | R11 / R12；S003 / S004 / S009 |
| 对象主次 | 所有图标都有强高光和大阴影 | 强调主对象，简化辅助对象 | R04 / R14 |
| 字体与标签 | 伪文字、字体漂移、模糊化学式 | 在可控软件中重排文字并逐字核对 | R15，PR20 |
| 连接线 | 断头、穿标签、不明双向箭头 | 按关系表重画，每种含义有图例 | R07 / R15 |
| 配色 | 新对象就加一种饱和色 | 固定对象/关系色，不靠颜色单独传递证据 | R05 / R06 |
| 原创性 | 与无关论文只有标题不同 | 用本研究的对象、条件、问题重建结构 | R16；S006 |
| 人工不规则 | 随机噪点、抖线、伪手绘 | 恢复有意图的一致性 | R16，PR20 |
| 最终扣除 | 装饰删掉后主信息完全不变 | 删除该元素，再检查阅读层级 | R14 / R20 |

## 例外与验收

若光照本身是实验变量或材料透明度解释真实空间关系，可保留明确标记的效果；不得把效果变成未验证的能量路径。记录例外理由、参考角色和对应事实。沿用 PR20 的 rendering intensity 默认 2/5 与其 AI Flavor Score；这只是当前接口快照，不是本模块新发明的社区共识。

终稿由科学语义、使用尺寸可读性、视觉一致性、编辑能力与权利条件共同决定。若用户需要可编辑 PowerPoint，必须是可编辑原生对象，不能把一张成图贴入幻灯片后称为可编辑交付。本批仅交付参考，不生成科研终稿，也未完成真实任务用户盲读测试。
