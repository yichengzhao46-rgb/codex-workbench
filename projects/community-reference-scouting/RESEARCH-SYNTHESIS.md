# 研究总结：从“好看的图”到可检验的设计选择

## 主要结论

这批公开经验最值得复用的是信息组织：先决定要说什么，再决定主次、方向、分组与对象表示方式。高级感不能用 3D 程度、图标数量或“Nature 配色”来代理。BioRender 的原始教程支持清晰阅读方向、受控颜色、箭头层级与对齐；社区对模板感的抱怨则提示要保留研究特异信息，但它不是审美普查。[S001](https://www.biorender.com/blog/top-4-tips-for-designing-a-graphical-abstract)、[S006](https://www.reddit.com/r/labrats/comments/1vup1ss/any_suggestion_for_graphical_abstracts/)

## 五种任务，五种读者问题

| 任务 | 第一眼应回答 | 推荐构图候选 | 常见失败 |
| --- | --- | --- | --- |
| Graphical abstract | 主要发现是什么？ | 输入/干预 → 关键过程 → 结果 | 把所有实验方法列为等权图标 |
| First figure | 研究体系和问题如何组织？ | 总览 + 放大/剖面 + 条件定义 | 无证据地宣传“第一张图必须是概念图” |
| Mechanism schematic | 什么通过什么路径改变什么？ | 实体/区室 + 有定义的连接线 | 将叙事箭头、通量和假设混画 |
| Material–microbe interface | 哪个接触面或空间关系重要？ | 一个界面主图 + 必要局部放大 | 高光纹理盖过接触关系 |
| 2D–2.5D illustration | 深度增加了什么信息？ | 平面逻辑 + 克制的体积/剖面 | 让每个对象都产生阴影和辉光 |

上述任务映射是本项目的设计综合，不是某一社区的统一规范。布局建议参考 [S002](https://www.simplifiedsciencepublishing.com/resources/best-graphical-abstract-examples-with-free-templates)；混合空间/剖面实例见 [S009 Figure 1](https://esurf.copernicus.org/articles/6/687/2018/)。

## 冲突建议如何处理

| 分歧 | 来源实际说了什么 | 本项目处理 |
| --- | --- | --- |
| 渐变/阴影是否“专业” | S003 演示体积效果；S001 将装饰阴影列为常见问题 | 保留能解释形状或层次的低强度效果；不把教程效果当发表标准 |
| 自定义 vs 图标库 | S006 发帖者不喜欢模板同质化；S005 评论者谈到编辑统一样式 | 统一视觉语法，同时定制研究特异对象；不默认弃用 BioRender |
| 2D vs 3D | S004 的地形确有空间表达需求；S007 有人认为普通论文不需光线追踪 | 按信息需求选择；封面、空间关系和机制逻辑采用不同强度 |
| 极简 vs 科研细节 | 少量标签可提高浏览速度，但机制图需要准确命名和证据区分 | 首层简洁、次层必要细节；不得删除理解机制必需的信息 |
| 顶刊风格 vs 科学质量 | S005 含作者重绘经历；S016 公开段落确认 art editor 的工作 | 只提取编辑过程经验，不承诺接收率或称某种风格为顶刊必要条件 |

完整出处和访问层级见 [source notes](evidence/source-notes.md)。其中 S003 是文本证据，未把它的示例图记为已直接目视分析。

## 面向 Bath/MOB 的应用建议（设计提案，不是新增科学结论）

- **Bath–RP 双伙伴图**：用左右实体和中间交换空间组织信息；分别标记碳流与电子候选路径。若项目只支持可溶物交换，不能为了简洁改画直接电子桥。
- **Bath–Bio-Se / 材料界面**：把形成阶段与后续功能测试分开；低强度 2.5D 可描述材料位置，不能用发光粒子暗示已证实的电子注入。
- **环境到机制的首图**：可借 E004 的尺度切换方式，但重建本研究的对象与逻辑，不搬用其土壤过程，也不复制整图布局细节。
- **不同氧条件**：采用位置一致的平行对照，保留同一实体颜色；数量或大小的变化必须有数据依据。
- **概念图混入组学结果**：本模块只处理概念层角色；PCA、富集、火山图和组学热图交给 PR21。
