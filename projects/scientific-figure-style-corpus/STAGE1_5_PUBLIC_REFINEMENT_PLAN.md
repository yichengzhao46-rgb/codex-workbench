# Stage 1.5 public refinement plan

## Goal

Strengthen the active style-learning subset by adding **40–60 recent (2024–2026) open-access figures** that are highly relevant to:

- mechanism / integrated mechanism;
- microbial interaction / cross-feeding;
- electron transfer / redox-mediator pathways;
- material–microbe interfaces / biohybrids / semiconductor interfaces;
- environmental gradients / oxic–anoxic or redox-stratified layouts.

This stage does **not** replace the validated 100-image raw corpus. It adds a targeted refinement layer intended to increase the number of **A+B style references** from 42 toward 80–100.

## Public-only rights rule

Only figures with redistribution-compatible licenses should enter the public image layer.

- **Allowed**: CC BY / CC0 / equivalent explicit redistribution permission.
- **Not for public mirroring**: CC BY-NC, CC BY-ND, CC BY-NC-ND, publisher-restricted reuse, or unclear rights.

High-value but non-redistributable papers may still be recorded later as **metadata/private-reference-only** items.

## Selection policy for figures

Each candidate paper may contribute **at most 2 figures**, and typically only **1** should enter the active style-learning pool unless a second figure provides a distinctly different and high-transfer layout.

Prioritize figures that are primarily:

1. integrated mechanism;
2. microbial interaction schematic;
3. electron-transfer mechanism;
4. material–microbe interface;
5. environmental-process or environmental-gradient overview;
6. experimental design only when the layout is unusually reusable.

Exclude or heavily down-rank:

- routine bar/line/scatter plots;
- ordinary PCA/heatmaps/volcano plots;
- microscopy-only figures;
- figures whose main value is data rather than visual language.

## Output targets

For each selected figure, capture:

- `candidate_id`
- source article
- figure locator
- rights status
- figure purpose
- style family
- layout archetype
- style-learning tier (A/B/C/exclude)
- transfer value for Bath–RP project
- notes on why the figure works
