# M004

## 1. Figure identity
- Canonical ID: M004
- Legacy ID: S026
- Source type: local curated asset
- Visual class: material–microbe interface / biohybrid electrode overview

## 2. Functional role
This figure explains how one central biohybrid electrode can support several electron-transfer modes and then connects those modes to downstream applications. It is a strong interface-centered overview rather than a molecular pathway diagram.

## 3. Layout and reading logic
A tall central biohybrid electrode is the hero object. Three numbered circular callouts on the left decompose indirect, direct and interfacial electron-transfer modes. Two application boxes on the right show where the interface is used. Reading order is center → left mechanism modes → right application outcomes.

## 4. Cell / object rendering
Rod-shaped cells are rendered with restrained 2.5D volume and clustered densely on a dark porous electrode. The material and cells are visually distinct by texture, value and color. Callout bubbles simplify contact geometry rather than reproducing full cellular anatomy.

## 5. Arrow grammar
Red e− arrows carry charge/electron semantics. Green arrows leave the central electrode toward application outcomes, so electron flow and system-level use are never confused. Numbered callouts act as a third connector grammar for explanatory decomposition.

## 6. Palette / outline / text hierarchy
The palette is restrained: pale cyan background, pink microbes, charcoal electrode, red electron accents and green application arrows. Large numbered mechanism labels and application titles dominate; detailed labels remain secondary.

## 7. Information density and evidence style
The figure is medium-to-high density, but whitespace around the central hero object prevents overload. Mechanistic detail is concentrated inside the three zoom bubbles. This is conceptual rather than evidence-heavy.

## 8. Best reusable elements
- central hero material–microbe object;
- three mechanism zoom bubbles around one interface;
- semantic separation of electron arrows and application arrows;
- one interface feeding multiple downstream functions.

## 9. Suitable future use cases in Bath–RP project
Very useful for GAC-facilitated interspecies coupling, Bath–Bio-Se interfaces, electrode-associated EEU/EET concepts, or any figure where one conductive/material interface needs to be explained through several possible interaction modes.

## 10. Weaknesses / what not to imitate
Avoid excessive texture or photorealism on the electrode. More than three or four zoom bubbles would fragment the story. The central object should remain dominant; callouts should explain it, not become separate mini-figures.
