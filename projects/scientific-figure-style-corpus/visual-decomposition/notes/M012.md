# M012

## 1. Figure identity
- Canonical ID: M012
- Legacy ID: Z072
- Source type: local curated asset

- Cross-library note: conceptually overlaps with bioinformatics reference BI019

## 2. Functional role
This figure converts several transcriptomic summaries into one large interaction/self-adaptation mechanism. Its main value to the main library is composition and information hierarchy; biologically it sits close to the bioinformatics library.

## 3. Layout and reading logic
Two circular heatmaps and three grouped expression bar panels occupy the upper/left evidence zone. A large integrated mechanism occupies the lower/right zone. The intended reading sequence is global pathway response → specific functional modules → combined IET/self-adaptation mechanism.

## 4. Cell / object rendering
The mechanism uses simplified community/cell compartments with functional icons rather than realistic microbes. Conductive pili, EPS, transporters and signaling elements are rendered as schematic modules embedded in the larger cell/interface diagram.

## 5. Arrow grammar
Black arrows handle ordinary metabolic flow. Green cues emphasize electron/interface movement. Orange dashed arrows and boxes emphasize regulatory/quorum-sensing steps. This multi-class connector system is effective only because each class is repeatedly reused.

## 6. Palette / outline / text hierarchy
Pastel blue/orange cell regions form the background scaffold. Pathway classes reuse the same accent colors across charts and the mechanism. Panel letters and boxed functional labels are essential because the canvas is very dense.

## 7. Information density and evidence style
Information density is very high. The figure works by strong panel boundaries and repeated categorical colors. It is a good evidence-to-model example, but too dense to serve as a default mechanism-only style.

## 8. Best reusable elements
- circular pathway heatmaps;
- grouped functional-expression modules;
- large integrated mechanism as the synthesis panel;
- consistent pathway color semantics across charts and mechanism;
- omics evidence arranged around a central interpretation.

## 9. Suitable future use cases in Bath–RP project
Useful for Figure 3.5-style transcriptomics integration: compact pathway response summaries surrounding a species-resolved or interaction mechanism. It should mainly guide composition, not cell rendering.

## 10. Weaknesses / what not to imitate
Do not use this density for a standalone mechanistic schematic. Avoid tiny labels and too many pathway colors. Because the same/similar reference also exists in the bioinformatics library, main-library retrieval should use M012 mainly for composition/information hierarchy and BI019 for omics-specific analytical precedent.
