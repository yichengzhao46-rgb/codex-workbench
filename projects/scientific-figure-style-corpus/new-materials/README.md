# new 素材

This is a human-curated visual-method reference library stacked on PR20.

## Purpose

The library stores reusable **drawing logic** rather than copying complete figures. Each NEW reference is decomposed into:

- composition
- hierarchy
- drawing idea
- object rendering
- palette
- connector grammar
- whitespace
- information density
- reusable rules
- best use
- avoid-transfer
- prompt logic

The intended workflow is multi-reference synthesis, e.g.:

> NEW007 for workflow composition + NEW002 for biological object rendering + NEW003 for connector/color grammar.

## Rights / storage policy

The source images were supplied in conversation as third-party style-reference screenshots. Redistribution rights have not been verified. Because this repository is public, the image binaries are **not mirrored in GitHub** under the existing PR20 rights policy.

They are catalogued as `restricted_reference_only`. The visual recipes below are original analytical notes and may be used freely inside the workflow. If redistribution permission is later confirmed, the original image files can be added under `assets/`.

## Integration with PR20

This library is intentionally separate from M001–M022. PR20 remains the canonical paper-figure grammar library; NEW001–NEW008 add explicit prompt/construction recipes for generation and anti-AI-look reconstruction.
