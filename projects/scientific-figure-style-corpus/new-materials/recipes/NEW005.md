# NEW005 — Desalination resource-recovery infrastructure hub

## Drawing idea
Use a lightly isometric engineering landscape to show one central infrastructure hub connected to functional zones.

## Composition
Core desalination system at center; marine energy and intake on water side; resource recovery/industry on one side; agriculture/application zones around the perimeter; pipes and power connections unify the system.

## Hierarchy
Central hub → functional zones → network connections → secondary technologies.

## Object rendering
Low-detail 2.5D infrastructure, restrained geometric shadows, repeated building/module forms, no photorealism.

## Palette
Pale aqua/green/blue field with muted grey equipment and limited warm accents.

## Connector grammar
Pipes and utility lines act as network grammar; avoid arrowing every connection.

## Whitespace
Generous around each zone; broad aerial view prevents crowding.

## Information density
Medium-high.

## Reusable rules
- Central-hub composition works when integration itself is the message.
- Network lines can replace conventional arrows.
- Repeated module design creates engineering coherence.

## Best use
Engineered ecosystems, reactor–resource networks, water–energy–food systems, chapter-level infrastructure concepts.

## Avoid transfer
Using isometric scenery for simple cell mechanisms; excessive facility realism; too many network lines.

## Prompt logic
Define the functional zones and center first, then the shared perspective, then network streams, then labels.
