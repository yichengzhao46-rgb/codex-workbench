# NEW006 — GIS / flood digital-twin system landscape

## Drawing idea
Layer physical geography, observation infrastructure, computation, uncertainty, and decision outputs in one coherent system.

## Composition
Continuous catchment landscape as base; observation network overlaid spatially; digital-twin engine as a compact functional node; decision outputs on the downstream/right side; uncertainty callouts at edges; small output insets at bottom.

## Hierarchy
Physical world → sensing → data assimilation/modeling → probability/output → action.

## Object rendering
Clean 2.5D landform, small standardized sensors/satellites/buildings, thin semi-transparent data links.

## Palette
Low-saturation green/blue/earth landscape, restrained technical blue overlays, neutral annotation boxes.

## Connector grammar
Physical flows follow geography; data links are thin/semi-transparent; callouts use light leader lines; decision outputs use clearer directional arrows.

## Whitespace
High despite complexity because labels are anchored in open terrain/sky margins.

## Information density
High.

## Reusable rules
- Separate physical and informational flows visually.
- Data layers should remain subordinate to the geographic scaffold.
- Edge callouts are useful for limitations/uncertainty without interrupting the central story.

## Best use
Sensor-driven environmental systems, multi-scale observation, GeoAI/digital twin, complex monitoring workflows.

## Avoid transfer
Dense callouts in simple figures; making data lines look like physical transport; 3D realism.

## Prompt logic
Decompose prompt into title/layout/style/scene/observation/data pipeline/callouts/insets before rendering.
