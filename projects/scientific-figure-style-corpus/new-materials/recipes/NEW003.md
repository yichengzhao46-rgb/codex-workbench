# NEW003 — Nature Reviews hydrogen systems synthesis

## Drawing idea
Convert review-level complexity into controlled information architecture.

## Composition
Linear process spine → parallel technology alternatives → branching storage/transport/end-use tree.

## Hierarchy
1. One unmistakable main route.
2. Repeated small-multiple modules for alternatives.
3. Branch tree for downstream applications.

## Object rendering
Clean technical icons, consistent scale, repeated module vocabulary, minimal decoration.

## Palette
Mostly neutral/cool technical tones with strict semantic colors for key species and energy carriers.

## Connector grammar
- Main process: one consistent arrow family.
- Alternatives: repeated short arrows and matched input/output geometry.
- Branch tree: shared trunk then equal-weight branches.
- Assign persistent colors to recurring scientific entities.

## Whitespace
Moderate and highly regular.

## Information density
High, controlled by repeated geometry and typography.

## Reusable rules
- Different relationship types may use different layout grammars in one figure.
- Semantic color should behave like a legend, not decoration.
- Repeated modules reduce cognitive load.

## Best use
Review syntheses, technology routes, experimental group comparison, workflow plus alternatives, chapter overview.

## Avoid transfer
Random colors, inconsistent arrow weights, unequal detail across alternatives, prose-heavy labels.

## Prompt logic
Specify canvas and panel logic; define relation type per region; define exact color semantics and arrow family; prohibit decorative styling.
