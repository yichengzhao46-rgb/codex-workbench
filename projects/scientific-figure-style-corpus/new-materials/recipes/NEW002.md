# NEW002 — Layered biomedical delivery and immune mechanism

## Drawing idea
Tell a biological story in vertical layers: preparation → systemic delivery/local action → downstream biological outcome.

## Composition
Narrow top preparation strip; large central hero scene; lower outcome/immune sequence.

## Hierarchy
1. Engineering/preparation.
2. Delivery/targeting/local release.
3. Cellular response and final phenotype.

## Object rendering
Soft editorial biological icons: very light volume, thin outlines, subtle internal shading, no glossy 3D. Cells and vesicles are standardized reusable components.

## Palette
High-lightness pastel system: mint/teal, coral-pink, sky blue, muted lavender, lots of white.

## Connector grammar
Short directional arrows within each scale; one or two scale-transition connectors; inset only where mechanistic detail earns it.

## Whitespace
High. Separate layers by empty space rather than heavy boxes.

## Information density
Medium.

## Reusable rules
- Macro biological scene and micro mechanism can coexist if scale transitions are explicit.
- Object identity should be preserved by color across scales.
- Use 80%+ white/near-white canvas; color only for semantic grouping.

## Best use
Cell–cell interaction, biohybrid delivery, donor-recipient biology, experimental system with downstream phenotype.

## Avoid transfer
Strong glow, saturated pink/blue, decorative gradients, over-detailed cell surfaces.

## Prompt logic
Define story layers first; specify object identities and semantic palette; prohibit heavy shadows/3D; use concise labels after layout is stable.
