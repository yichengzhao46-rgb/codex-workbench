# PR-EXP-Workflow v1｜实验流程图专用绘图方案

日期：2026-10-03。版本：v1.0。基础画风：SoftSci-v2，吸收本次 Fig. 3.1a / Fig. 3.2 的逐轮反馈。

状态：实验性 PR 方案与可复用绘图流程，通过独立 Draft PR 提议；未经合并批准，也不是已安装的 skill。适用于后续按本文件执行的任务。无需将这套规则自动套用于机制图或数据图。

## PR 摘要

### 要解决的问题

仅用“期刊风、柔和配色”描述风格不足以稳定复现。连续改图会出现颜色逐渐变艳、仪器难以区分、同级标题不一致，以及标记和分析步骤连接错误。实验流程图需要同时管理科学流程、器材语义、视觉风格与最终输出尺寸。

### 本方案增加什么

建立一套从实验事实表、布局选择、原创绘制、逐项复核到 PNG / TIFF 交付的完整流程。采用白底与自然留白、柔和灰蓝器材、有限浅透视；将分组归属、独立取样、操作先后和计算连线作为硬性验收项目。用已认可图作为视觉锚点，用反馈记录限制版本漂移。

### 预期行为

输入一份实验方法或旧图，先保留实验事实，再根据分析路线组织画面；首次提供 PNG 预览，按用户确认局部修改，确认后导出指定物理尺寸的 TIFF。新图不因“美观”而改变方法，局部修改不触发无关重排。

## 1. 使用范围与调用

适用于培养体系建立、分组处理、取样、样品制备、仪器分析，以及相互平行的分析路线。微生物、环境、生态与生物工程实验均可使用。

不自动用于电子传递机制图、图文摘要、统计图或结果推断图。流程箭头描述操作与样品去向，不承担机制证据含义。

推荐调用：

> 按 PR-EXP-Workflow v1 绘制实验流程图。使用附件中的最新版作为风格锚点；依据我提供的方法确认分组、操作和输出。先给 PNG 预览，同级标题统一，不改变科学内容。

新对话中附上本方案或完整包；不能假定仅凭名称就能读取此方案。这里的“持续完善”指每次任务中有记录的迭代，不代表后台自动检索或模型训练。

## 2. 优先级与输入事实表

优先级：用户最新明确指令 > 本次确认的方法事实 > 最新认可图的局部风格 > 本方案默认值 > 新检索的美术参考。

绘制前建立下表。已有信息直接使用；缺少且会改变实验含义的内容才向用户核实。未知参数不补猜测值。

| 字段 | 需要确认的内容 |
|---|---|
| 图的任务 | 体系建立、操作流程、样品制备或平行分析路线 |
| 输出 | 宽 × 高，mm；PNG 预览；确认后的 TIFF 分辨率 |
| 培养组 | 名称、活/灭活、单/共培养、重复数（若需要显示） |
| 条件 | 容器、气相组成和体积、液相体积、温度、光照 |
| 操作 | 动作、先后顺序、样本形态、是否破坏性取样 |
| 分支 | 每组进入哪些路线；哪些是独立处理而非混样 |
| 检测 | 分析对象、方法/仪器、输出指标 |
| 计算 | 输入量、单位转换、允许求和的量 |
| 锁定项 | 已认可的布局、图标、文字、颜色与本次允许修改的区域 |

形成简短的内容合同，至少列出 groups、routes、steps、labels、conditions、must_not_connect、locked_elements。逐一核对后再画，不能直接让图像模型自行补全实验。

## 3. 风格：白底柔彩科研流程

- 纯白背景，用留白、对齐、短标签和细箭头组织信息。
- 2D 为主；瓶口、仪器顶面、侧面使用克制的浅 2.5D。
- 器材浅灰蓝，液体淡青/浅粉，细胞哑光；局部渐变仅辅助识别器形。
- 同一图的器材视角、线宽、细节量和视觉大小一致。
- 不使用大块彩色底板、粗框、灰虚线分区、巨型编号和装饰性横幅。
- 不使用强高光、玻璃反光、深阴影、球体质感、写实纹理或商业海报效果。
- 低饱和主要作用于图形，文字保持足够对比度。不能全图统一降低对比度导致文字发灰。
- 不要求图标真实比例，但要真实表达关键结构和操作位置。

## 4. 布局模板

### A. 体系建立—取样—检测（Fig. 3.1a）

主阅读方向从左向右：Preculture treatment → Experimental groups → Sampling → Measurements。

- 四个逻辑区域用位置表达，不加四块独立底板。
- 培养组平行等距，共同条件放在组下方，用细括号明确作用范围。
- Sampling 分开画 headspace gas 和 culture aliquots。
- 检测仪器纵向排列，图标在左，标题与指标在右；文字左边界和仪器中心轴分别对齐。
- 一台仪器用于多个相关指标时可以共享图标，但指标标题仍按相同层级呈现。
- 用“Each group separately”明确独立取样；括号/公共路线表达相同处理流程，不暗示把三组混成一管。

### B. 多条平行分析路线（Fig. 3.2）

左侧展示培养组，右侧按分析目的分两条水平路线。短路线在上，制样较长的路线在下。

- 仅进入某一路线的对照放在该路线入口附近。
- 标记培养位于取样之前；示踪试剂指向培养阶段，不能连到末端仪器。
- 标签“4 groups / Processed separately”紧邻对应组别及路线入口。
- 长路线允许分成两行，但回转箭头必须清楚，且操作不重复、不漏项。
- 冷冻—冻干、均质—称量等相邻操作可用缩短间距自然成组，不能因此交换先后顺序。
- 对不同物理量先换算再汇总；TC 与 IC 不能重复计入无机碳求和。

### C. 单线或分支实验

步骤少时使用单条横向路线。条件分支时采用平行、结构对齐的路线。避免过早采用蛇形流程；优先减少重复器材或冗长标签，再考虑换行。

### 尺寸适配

先确定最终宽高，再安排文字和图标。130 × 56 mm 是本次 Fig. 3.1a 的规格，不是所有图的默认尺寸。首次绘图应在目标比例内直接构图；已有认可图改画布时等比适配，可补白，不能拉伸、裁掉科学内容或未经要求改排版。

## 5. 字体与标题层级

正式可编辑排版用 Arial；RP 需要斜体时仅改变 RP，不连带 Bath。图像生成中的字体只能视为近似，不宣称已使用/嵌入真实 Arial。

| 层级 | 内容 | 规则 |
|---|---|---|
| 一级 | 四个阶段标题/分析路线标题 | 同字号、同字重、同颜色 |
| 二级 | Growth、RP pigment、TCP、DCW、Spatial association 等 | 同字号、同字重；标题加粗 |
| 指标/方法 | OD₆₆₀、A₈₀₅/A₈₆₄、qPCR、FISH、Biomass | 常规字重，与相邻同类文字一致 |
| 条件/注释 | 温度、体积、独立处理说明 | 较低层级，避免小到不可读 |

本次锁定：

- **Growth** | OD₆₆₀：仅 Growth 加粗，OD₆₆₀ 不加粗。
- **RP pigment** | A₈₀₅/A₈₆₄：RP pigment 与 Growth 同级；RP 粗斜体，pigment 粗正体；指标不加粗。
- TCP 和 DCW 下一级均写 Biomass，常规字重。
- Bath–RP 组名绿色，仅 RP 斜体。
- 上下标必须正确，不能将 ¹³C、CH₄、O₂ 或波长数字混为普通基线文字。

新排版以最终物理尺寸检查字号：主体标签优先约 7–9 pt，阶段标题约 9–11 pt，次级注释尽量不低于 6 pt。这是工作起点，不是期刊硬性标准；空间不足优先精简文案或调整布局。旧图等比导出不等于通过此字号检查，不能声称所有旧图已达到上述值。

## 6. 器材画法与语义

| 对象 | 识别结构 | 必须避免 |
|---|---|---|
| 血清瓶 | 短铝盖、中央橡胶塞、明确气液界面 | 螺纹试剂瓶盖；已知小液量却画满瓶 |
| 250 mL 培养体系 | 200 mL headspace + 50 mL medium；示意低液位 | 把液柱高度视为精确体积刻度；细胞漂在气相 |
| 气体取样 | 气密注射器/针头，连到气相分析 | 连到菌体收集支路 |
| 液体取样 | 移液器、离心管 | 把移液动作直接叫 biomass recovery |
| 分光光度计 | 单个矩形比色皿插入打开的样品仓 | 做成多孔热循环仪；只在旁边放比色皿 |
| qPCR | 掀盖热循环仪、明显多孔反应板 | 与分光光度计同形 |
| TCP | 试剂盒包装与试剂瓶 | 未用方法对应的独立仪器 |
| DCW | 滤纸置于天平上称量 | 画成称锡杯；在简版中重新展开全套前处理 |
| 离心 | 有管位/转子的离心机 | 单纯取样管代替离心 |
| 同位素称量 | 天平上小锡杯及少量粉末 | 大浅盘代替小锡杯 |
| EA–IRMS | 两个相连分析模块，短标签 | 任意单一光谱仪图标；虚构结果图 |

细菌元素保持简化，不添加未经要求的膜蛋白、鞭毛和细胞内纹理。具体仪器不冒充型号精确图。

## 7. 箭头与科学逻辑

箭头使用细实线和小箭头头部，同种含义同线宽。每根箭头都有可解释的起点和终点。颜色区分分析路线，不能代替分组标签。

分支意味着同源样品进入不同检测；汇合必须区分“相同操作模板”“样品混合”和“数学求和”。如果样品未混合，图注或入口直接写 separately，避免连线画成实际合并液体。

硬性错误：对照进入错误路线；标记出现在取样或检测之后；取样和离心颠倒；漏洗涤/冻干；箭头跨线误接；TC 被加进 IC；单位不同直接相加；示意图暗示没有证据的物种特异性 ¹³C 固定。

## 8. 本项目内容合同示例

### Fig. 3.1a：当前认可内容

- Bath、RP 分别 harvest、wash、resuspend；建立 Bath-only、RP-only、Bath–RP 共培养。
- Headspace (200 mL): 25% CH₄ + 5% O₂ + 70% Ar；Medium: 50 mL；dark；37 °C。
- 三组分别取样；headspace → CH₄/O₂；culture aliquots → FISH、OD₆₆₀、A₈₀₅/A₈₆₄、TCP、DCW、qPCR。
- TCP 用试剂盒图标。DCW 实际方法为过滤、收集滤纸、烘干后称重，图中按用户要求只留滤纸称重图标。
- 图中装置与条件用于本实验，不作为其他研究默认值。

### Fig. 3.2：布局案例，仍按后续反馈校准

- Carbon-pool：三组活体系 → cell-free supernatant（TC、IC）和 headspace CO₂。
- 只有 IC 与 headspace CO₂-C 在统一碳质量基础上求和；TC 单独终止。
- Stable-isotope：三组活体系 + heat-killed coculture 背景对照；NaH¹³CO₃ labeling 在取样前；四组分别处理。
- 操作：Sample collection → Centrifugation / Biomass recovery → Washing → Freeze at −80 °C → Freeze-drying → Homogenization → Weigh into tin capsule → EA–IRMS。
- 输出：δ¹³C、atom% ¹³C、background-corrected ¹³C excess；不自动添加物种分辨结论。
- 若以 mg C per bottle 汇总，液相 IC 浓度乘对应液体体积；气相 CO₂ 换成碳质量时考虑气相体积、压力、温度及实际报告条件。这里是换算框架，不能声称未知的 P/T 已被测量。
- 当前 Fig. 3.2 仅作流程布局案例，不用其全部绿色组名、锡杯外观或未确认细节覆盖 Fig. 3.1a 的最新规则。

## 9. 执行流程

1. 读取最新原图、用户最新反馈和实验事实，不仅依赖历史摘要。
2. 写内容合同和修改清单，锁定不应改变的内容。
3. 选 A/B/C 布局，先确定物理比例、组别和路线拓扑。
4. 指定输入角色：edit target、style reference、局部器材参考；不能混淆内容图和风格图。
5. 使用 imagegen 生成/修改科研插画预览；若用户已指定可编辑、代码或既有原生绘图工程，则使用适合该工程的方法。不声称生成位图是矢量或可编辑元素。
6. 先检查科学路线，再检查文字与美术；不是先挑最漂亮一张直接交付。
7. 局部反馈只改指定对象、字重或标签；再次检查全图是否漂移。生成模型不能保证局部像素完全不变，不作此承诺。
8. PNG 供用户检查。确认后按指定尺寸与 dpi 导出 TIFF；本项目默认不输出 SVG。
9. 保存原始图、当前认可版、输出规格、提示词/修改清单、QA 与参考来源，以便下一轮复用。

## 12. QA 与验收清单

### 科学逻辑（全部通过后才交付）

- [ ] 组名、数量、活/灭活状态与确认方法一致。
- [ ] 每组只进入正确路线，独立处理没有画成实际混样。
- [ ] 标记培养位于取样前，试剂不直接连 EA–IRMS。
- [ ] 制样步骤顺序正确、无遗漏、无重复。
- [ ] 每根箭头可追溯，不穿过文字或误连。
- [ ] 计算单位一致；TC 不加入无机碳求和。
- [ ] 无新增实验参数、结果趋势或物种特异性结论。

### 视觉与文字
